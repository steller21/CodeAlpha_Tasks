# My Portfolio

## About the Project
This project is a personal portfolio website created to showcase skills, experience, and a digital resume. It utilizes CSS animations to create an engaging user experience when the page loads.

### Features
- **CSS Animations:** The header fades in, while content sections slide in from the left and right for a dynamic entrance.
- **Hero Section:** A split layout design to present introductory information.
- **Resume Container:** A styled section specifically designed to highlight professional background.
- **Interactive Elements:** Hover effects on sections to improve user engagement.

### Technologies Used
- **HTML5:** Semantic structure of the portfolio.
- **CSS3:** Advanced styling including `@keyframes` animations, flexbox layouts, and background handling.
