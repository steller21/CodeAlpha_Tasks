# Simple Calculator

## About the Project
This is a simple, functional calculator web application developed as part of the CodeAlpha internship tasks. It features a modern dark-themed user interface designed with CSS grid for layout precision.

### Features
- **Basic Arithmetic:** Supports addition, subtraction, multiplication, and division.
- **Dark Mode UI:** A sleek, user-friendly interface with visual feedback on button clicks.
- **Delete Functionality:** Includes a 'DEL' button to remove the last input and a 'C' button to clear the display.
- **Responsive Grid:** Buttons are organized in a clean grid layout for ease of use.

### Technologies Used
- **HTML5:** Structure of the calculator.
- **CSS3:** Styling, grid layout, and dark theme aesthetics.
- **JavaScript:** Logic for handling calculations and user interactions.
